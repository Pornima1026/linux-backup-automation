# Linux Backup Automation Script

A beginner-friendly Linux shell scripting project that automates folder backups using Bash and rsync.

## Features
- Automatically creates timestamped backups
- Copies multiple folders
- Uses rsync for efficient file transfer
- Shows progress while backing up
- Skips missing folders safely

## Technologies Used
- Linux
- Bash Scripting
- rsync
- Shell Commands

## Commands Practiced
- mkdir
- rsync
- date
- arrays
- loops
- if conditions

## How to Run

```bash
chmod +x backup.sh
./backup.sh
